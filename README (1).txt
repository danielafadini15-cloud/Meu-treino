MEU TREINO — aplicativo PWA instalável

Para instalar no Android, o aplicativo precisa estar hospedado em um endereço HTTPS. Esta pasta já contém os arquivos necessários.

MODO MAIS SIMPLES (GitHub Pages gratuito):
1. Crie/entre em uma conta em https://github.com
2. Crie um repositório novo (ex.: meu-treino).
3. Envie TODOS os arquivos desta pasta para o repositório (Add file > Upload files).
4. No repositório, Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch; Branch: main; folder: /(root); Save.
6. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages (formato https://SEU-USUARIO.github.io/meu-treino/).
7. No Android, abra esse endereço no Chrome. Menu ⋮ > “Adicionar à tela inicial” ou “Instalar app”.
8. Confirme. O ícone Meu Treino aparecerá na tela inicial.

Os dados de séries/cargas são guardados localmente no navegador/aplicativo. Use Exportar backup periodicamente para salvar um JSON e Importar backup para restaurar.

Não há servidor nem conta: os dados ficam no aparelho. Se limpar dados do navegador ou trocar de celular, restaure o backup.
